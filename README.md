**Mira Browser** is a top-grade, hardware-accelerated Chromium mobile web browser for Android and the Web featuring an AI Assistant drawer, Speed Dial start dashboard, distraction-free reader mode, and dynamic glassmorphic themes. Built with Android 15 (SDK 35) Edge-to-Edge display support, Predictive Back navigation, and scoped storage security compliance.

Developed by **Ayyappa Pravin** (<apravint@gmail.com>).

---

## ⚡ Key Features

- 🌐 **Native Chromium WebView Engine**: Hardware-accelerated navigation handling HTTP/HTTPS URLs natively without iframe CORS or `X-Frame-Options` restrictions. Real web pages (Google, YouTube, DuckDuckGo, Wikipedia, Reddit, GitHub, ChatGPT) load at maximum speed.
- ⚡ **Mira AI Assistant**: Slide-out AI assistant capable of instant page summarization, key takeaway extraction, and language translation.
- 🚀 **Speed Dial Dashboard**: Interactive start screen with top site tiles and instant search.
- 🎨 **Glassmorphic UI & Themes**: Tokyo Night, Catppuccin, Nord, Cyberpunk, and OLED Dark themes.
- 📖 **Distraction-Free Reader Mode**: One-tap text extraction removing ads and clutter.
- 🖼️ **Custom Vector Launcher Icon**: Crisp neon vector launcher icon (`ic_launcher.xml` & adaptive XMLs).
- 🛡️ **Dual Asset Mirroring**: Serves resources from both `file:///android_asset/index.html` and `file:///android_asset/web/index.html`.
